# Security Policy

## Supported Versions

Please check whether the issue affects the latest stable release. If you found it in an older release or a development build, include the exact version or commit. [GitHub Releases](https://github.com/WanThinnn/Hybrid-PQ-CP-ABE/releases)

## Reporting a Vulnerability

Email [iam.elio2415@gmail.com](mailto:iam.elio2415@gmail.com?subject=%5BSecurity%5D%20Hybrid%20PQ-CP-ABE) to report a suspected vulnerability privately. This covers the native library and CLI, Python and Node.js/WebAssembly packages, Vault plugin, and release artifacts. Please keep vulnerability details out of public issues and pull requests while the report is being investigated.

Include the following where available.

- The affected component, version or commit, and installation source.
- Your operating system, architecture, and relevant runtime version.
- Steps to reproduce the issue with test data, along with the expected and observed behavior.
- The potential impact and any relevant logs with sensitive information removed.

Use test keys and synthetic data. Keep production keys, credentials, plaintext, and personal data out of the report.
